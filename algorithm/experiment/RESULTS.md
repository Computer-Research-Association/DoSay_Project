# 사과게임 알고리즘 실험 전체 기록

합 10 사각형 제거 게임(9×18). 목표 = 총 제거 칸 수 최대화(만점 162).
모든 실험은 **고정 시드 세트(1234~)** 로 돌려 paired A/B 비교. 병렬 실행.

## 최종 성과 요약

| 접근 | 최고 점수 | ratio | 판수 | 비고 |
|---|---|---|---|---|
| random baseline | 97.9 | 0.60 | — | (팀원 벤치마크) |
| **Greedy** (nine+eight+action_count) | 115.52 | 0.71 | 100 | heuristic |
| **Beam search** (5,3) + diversity | 119.22 | 0.735 | 100 | heuristic 천장 |
| **Simulated Annealing** (20000 iter) | **134.8** | **0.832** | 20 | 🏆 2분/판 |

핵심: heuristic(greedy/beam)은 ~119가 천장. **수순 어닐링**이 134.8로 +15.8 도약.

## 실험 인프라

| 파일 | 역할 |
|---|---|
| `experiment.py` | greedy 버전 실행/저장/비교, multiprocessing 병렬 |
| `beam.py` | 빔서치 실행 (width/depth/alpha/weights 인자) |

| 병렬 | greedy/beam=Pool, anneal=xargs 단판(‑P) — macOS fork+numpy 데드락 회피 |

버전 파일: `algorithm/models/version/<Type>_V##x.py`, 결과: `results/*.json` (설정+지표+git_commit).

# 1단계 — Greedy 피처 엔지니어링

heuristic이 **수를 둔 결과 보드**를 평가, do_step이 그 합이 최대인 수 선택.
`sigmoid(x,k,x0)=1/(1+e^(-k(x-x0)))`

## 확정된 유효 피처 3개 (모두 weight 1.0)

```python
# 1. remove_nine — 9는 1로만 짝(9+1). 9/1 비율 나쁘면 페널티
n9,n1 = count(9),count(1)
if n9==0: 0.0
elif n1==0: -1.0
else: -sigmoid(n9/n1, 2.5, 1.0)

# 2. remove_eight — 8은 2로 짝(8+2). +2.76 기여
-sigmoid(n8/n2, 2.5, 1.0)

# 3. action_count — 유효 수 많을수록 보상(막다른 길 회피). +6.25 기여 (결정타)
sigmoid(len(valid_actions), 0.2, 15.0)
```

## 점수 여정 (100판)
```
random         97.9
+remove_nine  106.51  (+8.6)   [V4a]
+remove_eight 109.27  (+2.76)  [V4b]
+action_count 115.52  (+6.25)  [V8c]  ← greedy 최종
```

# 3단계 — Simulated Annealing (수순 어닐링) 🏆

heuristic의 벽(~119)을 우회. heuristic 없이 **수순 자체를 탐색**.

- **해** = 한 판의 액션 시퀀스
- **이웃** = 지점 t에서 다른 유효 수로 갈아타 → 뒤를 rollout 재플레이
- **rollout 정책** = 경량 (grid 레벨, Board 객체 미사용) — 속도 20배
- **적합도** = 총 제거 칸 수
- **초기해** = 경량 greedy 한 판

**모델 heuristic rollout (초기 버전):**

|---|---|---|
| 200 | 125.2 | 20s |
| 2000 | 131.5 | 203s |
| 4000 | 131.0 | 376s |

|---|---|---|---|

> 발견: 20배 속도개선으로 2분 안에 130+. iter는 20000에서 정체(~133 상한).

# 핵심 교훈 종합

1. **action_count(선택지 유지)가 greedy의 돌파구.** 위치·밀집·중앙 등 간접·전략 신호는 다 실패했지만, 직접·즉각 신호가 근시안을 보완.
2. **비율 피처는 희소한 짝(9,8)에서만 유효.** 7·6·5는 짝이 많아 무효.
3. **위치 피처는 근본적으로 안 통함** (greedy·빔서치 전멸). 개수가 위치의 결과를 이미 담음.
4. **정교화 ≠ 개선.** 8을 1+1까지 세기, 9 위치, 하드 우선 등 "더 똑똑한" 시도는 오히려 하락.
5. **weight 튜닝 무효.** Optuna(greedy·빔서치 둘 다) → 1:1:1이 최적, 튜닝은 노이즈/과적합.
6. **"많이 지우기"는 함정** (대조군·alpha+ 로 확인). "적게(효율적으로) 지우기"가 옳은 방향.
7. **heuristic 천장 ~119.** 빔서치 깊이로 +2.6이 상한.
8. **어닐링이 유일한 돌파구 (134.8).** 수순 자체를 탐색해 heuristic 벽을 우회. 경량 rollout으로 2분/판 실현.
9. **측정이 감을 반복해서 뒤집음** — spread(좋아보였으나 유해), diversity(미약하나 유일한 +), 어닐링 파라미터(감이 최적) 등.
